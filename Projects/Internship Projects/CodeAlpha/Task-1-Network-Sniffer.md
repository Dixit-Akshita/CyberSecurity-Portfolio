# 🔍 Basic Network Packet Sniffer

**Internship:** CodeAlpha Cybersecurity Internship
**Task:** Task 1
**Duration:** 10 August 2026 – 10 September 2026

## 📌 Overview

A basic network packet sniffer developed using Python and Scapy to capture and analyze network traffic.

## 🛠️ Technologies Used

* Python
* Scapy
* Npcap
* VS Code

## ⚙️ Features

* Captures network packets
* Displays source and destination IP addresses
* Identifies protocols
* Displays port information
* Shows packet length and payload details

## 🎯 Skills Demonstrated

* Network traffic analysis
* Packet inspection
* Python scripting
* Basic network security concepts
