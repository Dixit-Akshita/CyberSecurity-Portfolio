# 🔐 Cyber Security Awareness & Threat Analysis System

**Project Type:** College Academic Project
**Semester:** 6th Semester

## 📌 Overview

A cybersecurity awareness and threat analysis system developed to help users understand basic cybersecurity risks and perform simple security checks.

## 🧩 Modules

* **URL Checker** — Performs basic analysis of URLs to identify potentially suspicious links.
* **Password Checker** — Checks password strength based on common security criteria.
* **Security Awareness** — Provides information and guidance on common cybersecurity threats and safe practices.

## 🛠️ Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript

## 🎯 Key Features

* Basic URL security analysis
* Password strength checking
* Cybersecurity awareness content
* Simple web-based interface

## ⚠️ Project Limitation

The URL Checker is a **basic prototype** and does not provide comprehensive or guaranteed detection of all malicious or suspicious URLs.

## 📚 Learning Outcome

This project provided practical experience in:

* Web application development
* Basic cybersecurity analysis
* Security awareness
* Understanding common cyber threats
