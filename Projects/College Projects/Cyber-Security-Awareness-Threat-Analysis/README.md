# 🔐 Cyber Security Awareness & Threat Analysis System

**Project Type:** College Academic Project  
**Semester:** 7th Semester

## 📌 Overview

The Cyber Security Awareness & Threat Analysis System is a web-based application developed to help users understand common cybersecurity risks and perform basic security checks.

The project provides simple tools for identifying potentially suspicious URLs, checking password strength, and learning about cybersecurity threats and safe online practices.

## 🧩 Modules

### 1. URL Checker
- Performs basic analysis of URLs.
- Identifies potentially suspicious links based on basic checks.
- Helps users understand possible URL-related security risks.

### 2. Password Checker
- Evaluates password strength based on common security criteria.
- Checks password characteristics such as length and complexity.
- Provides basic feedback on password security.

### 3. Security Awareness
- Provides information about common cybersecurity threats.
- Explains safe online practices.
- Helps users understand phishing, password security, and other cyber risks.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Backend Framework:** Flask
- **Frontend:** HTML, CSS, JavaScript

## 🎯 Key Features

- Basic URL security analysis.
- Password strength checking.
- Cybersecurity awareness content.
- Simple and user-friendly web interface.
- Web-based access through a local development server.

## ⚙️ Installation & Setup

Follow these steps to run the project on your local system.

### Prerequisites

Make sure the following software is installed:

- Python 3.x
- pip (Python package installer)
- A web browser

### Step 1: Download the Project

Download or clone the project repository to your local system.

### Step 2: Open the Project Folder

Open the project directory in VS Code or any preferred code editor.

### Step 3: Install Dependencies

Open the terminal inside the project directory and install Flask:

```bash
pip install flask
```

If a `requirements.txt` file is available, use:

```bash
pip install -r requirements.txt
```

### Step 4: Run the Application

Run the main Python application file using:

```bash
python app.py
```

*Note: Replace `app.py` with the actual main Python filename if it is different.*

### Step 5: Open in Browser

After starting the Flask server, open the following address in your web browser:

```text
http://127.0.0.1:5000/
```

## ⚠️ Project Limitations

- The URL Checker is a basic prototype and does not provide comprehensive or guaranteed detection of all malicious or suspicious URLs.
- Password strength checking is based on common security criteria and does not guarantee complete password security.
- The project is developed for academic and educational purposes.
