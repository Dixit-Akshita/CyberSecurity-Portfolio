# Day 5 – Beach Bar

## Overview

The fifth room of the **TryHackMe Hacker Holidays 2026 CTF** focused on **Boot2Root** concepts. The challenge involved analyzing a web application, identifying weaknesses in its configuration, and progressing through multiple stages to gain elevated access within the target environment.

## Room Details

* **Platform:** TryHackMe
* **Event:** Hacker Holidays 2026
* **Room:** Beach Bar
* **Category:** Boot2Root
* **Difficulty:** Easy

## Scenario

At the Byte Lotus Hotel's Beach Bar, a guest-facing jukebox application appeared to offer more functionality than intended. The challenge encouraged participants to investigate the application's behavior, identify security weaknesses, and understand how misconfigurations can lead to broader system access.

## Objectives

* Analyze the target application.
* Identify security weaknesses.
* Gain access to the target environment.
* Escalate privileges through discovered weaknesses.
* Complete the challenge objectives.

## Concepts Covered

* Web Application Security
* Source Code Analysis
* Configuration Review
* Security Misconfigurations
* Privilege Escalation
* Boot2Root Methodology

## What I Learned

* Source code and application components can reveal valuable information during security assessments.
* Configuration files should be carefully reviewed for security risks.
* Small security oversights can have significant consequences when combined together.
* Privilege escalation often relies on identifying and leveraging existing weaknesses within a system.

## Key Takeaways

* Secure configuration management is a critical part of application security.
* Regular security reviews help identify unintended exposure.
* Defense in depth is important for reducing the impact of individual weaknesses.
* Understanding application architecture helps identify potential attack paths.

## Skills Practiced

* Analytical Problem Solving
