# Day 3 – Complimentary

## Overview

The third room of the **TryHackMe Hacker Holidays 2026 CTF** focused on **Cloud Security** within an AWS environment. The challenge demonstrated how misconfigured cloud services and overly permissive access controls can expose sensitive data, highlighting the importance of proper identity and access management in cloud-based applications.

## Room Details

* **Platform:** TryHackMe
* **Event:** Hacker Holidays 2026
* **Room:** Complimentary
* **Category:** Cloud
* **Difficulty:** Easy

## Scenario

Guests at the Byte Lotus Hotel were encouraged to install a complimentary wellness application that appeared to know personal information without requiring a traditional login process. The challenge explored how cloud-based authentication and authorization mechanisms can be misconfigured, potentially granting access to data beyond what users should be able to view.

## Objectives

* Investigate how the application obtains access behind the scenes.
* Understand cloud authentication and authorization mechanisms.
* Explore the impact of misconfigured permissions.
* Complete the challenge objectives.

## Concepts Covered

* Cloud Security
* Amazon Web Services (AWS)
* Amazon Cognito
* Identity and Access Management (IAM)
* Cloud Misconfiguration

## What I Learned

* Cloud applications often rely on identity services to provide temporary access to resources.
* Misconfigured permissions can unintentionally expose sensitive information to unauthorized users.
* The principle of least privilege is critical when assigning cloud permissions.
* Proper access control reviews help reduce the risk of data exposure in cloud environments.

## Key Takeaways

* Cloud security depends heavily on correctly configured authentication and authorization controls.
* Excessive permissions can significantly increase the impact of a security issue.
* Identity management services should be carefully configured and regularly audited.
* Security misconfigurations remain one of the most common causes of cloud data exposure.
