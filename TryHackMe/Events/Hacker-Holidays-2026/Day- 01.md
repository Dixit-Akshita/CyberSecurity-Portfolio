# Day 1 – The Concierge Knows Too Much

## Overview

The first room of the **TryHackMe Hacker Holidays 2026 CTF** introduced the concept of **AI Prompt Injection**. Through an interactive scenario, the challenge demonstrated how Large Language Models (LLMs) can be manipulated when they rely on user-provided context without proper validation, emphasizing the importance of secure AI system design.

## Room Details

* **Platform:** TryHackMe
* **Event:** Hacker Holidays 2026
* **Room:** The Concierge Knows Too Much
* **Category:** AI
* **Difficulty:** Very Easy

## Scenario

At the Byte Lotus Hotel, guests interact with an AI concierge named **VERA**. The challenge explored how carefully crafted prompts could influence the assistant's responses, demonstrating the security risks associated with trusting user input without sufficient safeguards.

## Objectives

* Interact with the AI assistant.
* Understand the fundamentals of AI Prompt Injection.
* Explore how prompt manipulation affects LLM behavior.
* Complete the challenge objectives.

## Concepts Covered

* AI Prompt Injection
* Large Language Model (LLM) Security
* Prompt Engineering
* Social Engineering
* Trust-Based AI Interactions

## What I Learned

* AI systems can be influenced through carefully crafted prompts when proper safeguards are not implemented.
* Trust assumptions play a significant role in the security of AI-powered applications.
* Prompt Injection is an emerging attack technique that highlights the need for secure prompt design and robust access controls.
* Understanding AI security requires both technical knowledge and an awareness of human interaction with AI systems.

## Key Takeaways

* Prompt Injection is a practical security concern for applications powered by LLMs.
* AI assistants should validate user input and avoid blindly trusting provided context.
* Secure AI development requires multiple layers of protection beyond prompt design.
* Responsible AI implementation is essential to reduce the risk of unintended information disclosure.
