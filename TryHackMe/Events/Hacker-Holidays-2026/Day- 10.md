# Day 10 – The Hollow Shell

## Overview

The tenth room of the **TryHackMe Hacker Holidays 2026 CTF** focused on **Web Security** and explored risks associated with file handling and user-supplied content in web applications.

## Room Details

* **Platform:** TryHackMe
* **Event:** Hacker Holidays 2026
* **Room:** The Hollow Shell
* **Category:** Web
* **Difficulty:** Medium

## Scenario

The Byte Lotus Hotel provided a portal that allowed users to upload custom content for display within the application. The challenge required investigating how uploaded content was processed and identifying weaknesses that could arise when validation and security controls are insufficient.

## Objectives

* Analyze the target application.
* Investigate file handling functionality.
* Identify security weaknesses.
* Understand the impact of improper validation.
* Complete the challenge objectives.

## Concepts Covered

* Web Application Security
* File Upload Security
* Input Validation
* Secure File Handling
* Security Misconfigurations

## What I Learned

* User-controlled content should always be treated as untrusted input.
* File upload functionality requires strong validation and security controls.
* Security weaknesses can arise when applications trust uploaded content without sufficient verification.
* Proper input validation is a fundamental component of secure application design.

## Key Takeaways

* File handling mechanisms should be carefully secured.
* Validation should occur on the server side rather than relying solely on client-side controls.
* Secure development practices help reduce the risk of application abuse.
* Defense-in-depth remains important when processing user-supplied content.
