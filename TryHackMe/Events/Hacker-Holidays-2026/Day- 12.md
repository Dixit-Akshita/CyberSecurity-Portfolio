# Day 13 – After Hours

## Overview

The thirteenth room of the **TryHackMe Hacker Holidays 2026 CTF** focused on **Windows Forensics** and **Persistence Analysis**. The challenge required investigating system artifacts to identify hidden configuration data, analyze a malicious component, and recover an embedded payload.

## Room Details

* **Platform:** TryHackMe
* **Event:** Hacker Holidays 2026
* **Room:** After Hours
* **Category:** Forensics
* **Difficulty:** Medium

## Scenario

After normal working hours, unusual activity was detected on the resort's back-office systems. Common Windows persistence locations did not reveal the source of the activity, requiring deeper investigation of the provided system artifacts.

## Objectives

* Analyze the provided forensic artifacts.
* Identify hidden custom configuration data.
* Locate the suspicious malicious component.
* Analyze the embedded payload.
* Decode the recovered data.
* Complete the challenge objectives.

## Concepts Covered

* Windows Forensics
* Windows Persistence
* System Artifact Analysis
* Reverse Engineering
* Payload Analysis
* Data Decoding

## What I Learned

* Not all persistence mechanisms are visible through common autorun locations.
* Raw system artifacts can contain important evidence that automated tools may overlook.
* Suspicious components should be analyzed carefully to understand their behavior and purpose.
* Payload analysis and decoding can help recover information hidden within malicious artifacts.

## Key Takeaways

* Effective forensic investigations require looking beyond common persistence mechanisms.
* Manual analysis can be valuable when automated tools fail to identify suspicious activity.
* Understanding Windows artifacts is an important skill for DFIR and SOC investigations.
* Persistence analysis requires both technical knowledge and careful examination of evidence.
