# Day 9 – CryptoCabana

## Overview

The ninth room of the **TryHackMe Hacker Holidays 2026 CTF** focused on **Cloud Security** within a Microsoft Azure environment. The challenge explored how trust relationships, cloud permissions, and secret management services can impact the security of cloud-hosted applications.

## Room Details

* **Platform:** TryHackMe
* **Event:** Hacker Holidays 2026
* **Room:** CryptoCabana
* **Category:** Cloud
* **Difficulty:** Medium

## Scenario

A cloud-hosted backup kiosk claimed to securely protect sensitive information for its users. The challenge required investigating the application's cloud environment, understanding how it interacted with Azure resources, and assessing the impact of trust relationships and permission configurations.

## Objectives

* Investigate the target application.
* Analyze exposed cloud-related information.
* Explore Azure resources and permissions.
* Understand secret management mechanisms.
* Complete the challenge objectives.

## Concepts Covered

* Cloud Security
* Microsoft Azure
* Azure Storage
* Azure Key Vault
* Identity & Access Management (IAM)
* Secret Management

## What I Learned

* Cloud applications often depend on multiple interconnected services and trust relationships.
* Proper permission management is critical for protecting sensitive cloud resources.
* Secret management services help secure sensitive data, but their effectiveness depends on correct configuration.
* Reviewing access controls is an important part of cloud security assessments.

## Key Takeaways

* Excessive permissions can significantly increase security risk.
* Secure secret storage is only effective when access controls are properly enforced.
* Cloud trust relationships should be reviewed regularly to minimize unnecessary exposure.
* Identity and access management play a critical role in securing cloud environments.
