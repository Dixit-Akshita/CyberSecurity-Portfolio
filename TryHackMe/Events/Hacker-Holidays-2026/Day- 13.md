# The Guestbook

## Overview

This AI-focused web security challenge explored how an AI system can become vulnerable when user-provided content is treated as trusted instructions.

## Room Details

* **Platform:** TryHackMe
* **Event:** Hacker Holidays 2026
* **Room:** The Guestbook
* **Category:** AI
* **Difficulty:** Medium

## Scenario

The challenge featured VERA, an AI-powered concierge that processed guestbook entries as instructions. The objective was to investigate the application's behavior and understand how user-controlled input could influence the AI system.

## Objectives

* Analyze the web application.
* Investigate how user input is processed.
* Identify the AI security weakness.
* Extract and decode the required information.
* Complete the challenge.

## Concepts Covered

* AI Prompt Injection
* LLM Security
* Web Application Security
* Input Validation
* Secure AI Design
* Data Encoding & Decoding

## What I Learned

* AI systems should not blindly trust user-provided instructions.
* User input must be properly validated and separated from system-level instructions.
* Prompt injection can become a security concern when LLMs interact with sensitive application functionality.
* Encoded data may require additional analysis during security investigations.
