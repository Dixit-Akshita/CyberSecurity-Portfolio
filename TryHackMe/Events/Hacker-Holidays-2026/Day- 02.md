# Day 2 – Room 404

## Overview

The second room of the **TryHackMe Hacker Holidays 2026 CTF** focused on **Web Directory Enumeration**. Through a web-based challenge, it demonstrated how hidden files and directories can unintentionally expose sensitive resources, reinforcing the importance of reconnaissance during web security assessments.

## Room Details

* **Platform:** TryHackMe
* **Event:** Hacker Holidays 2026
* **Room:** Room 404
* **Category:** Web
* **Difficulty:** Very Easy

## Scenario

At the Byte Lotus Hotel, an exposed service hinted that more existed than what was visible on the surface. The challenge encouraged participants to think like a security professional by exploring beyond the application's visible interface to identify hidden resources.

## Objectives

* Explore the target web application.
* Understand the concept of Web Directory Enumeration.
* Identify hidden resources within the application.
* Complete the challenge objectives.

## Concepts Covered

* Web Directory Enumeration
* Web Reconnaissance
* Hidden Content Discovery
* Source Code Exposure
* Web Application Attack Surface

## What I Learned

* Hidden files and directories may remain accessible even when they are not linked through the application's interface.
* Directory enumeration is an essential reconnaissance technique used during web security assessments.
* Misconfigured web servers can unintentionally expose development, backup, or sensitive resources.
* Reconnaissance is often the first step in identifying potential security weaknesses within a web application.

## Key Takeaways

* Web applications should be regularly reviewed for exposed files and directories.
* Removing unnecessary development and backup files before deployment helps reduce the attack surface.
* Reconnaissance techniques play a critical role in identifying security risks before exploitation.
* Small configuration oversights can lead to unnecessary information disclosure.
