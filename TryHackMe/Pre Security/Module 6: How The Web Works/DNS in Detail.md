## Overview
This room introduced the Domain Name System (DNS) and explained how it translates human-readable domain names into IP addresses. It also covered the DNS lookup process, different DNS record types, and the roles of Top-Level Domains (TLDs) and Second-Level Domains (SLDs) in domain name resolution.

## Topics Covered
- Domain Name System (DNS)
- DNS Lookup Process
- DNS Record Types
- Making DNS Requests
- Top-Level Domains (TLDs)
- Second-Level Domains (SLDs)

- Retrieved the required flag.

## Key Learnings
- Learned how DNS translates domain names into IP addresses.
- Understood the DNS lookup process and how a DNS request is resolved.
- Learned the purpose of common DNS record types such as A, AAAA, CNAME, MX, and TXT records.
- Understood the roles of Top-Level Domains (TLDs) and Second-Level Domains (SLDs) in domain names.
- Gained hands-on experience performing DNS queries to retrieve domain information.


## Summary
