# Extending Your Network

Platform: TryHackMe 

Path: Pre Security 

Module: 2

Status: Completed

## Overview
This room introduced the concepts used to extend and secure modern networks, including port forwarding, firewalls, Virtual Private Networks (VPNs), and Virtual Local Area Networks (VLANs). It explained how these technologies enable secure communication, control network traffic, and improve network organization.

## Topics Covered
- Port Forwarding
- Firewalls and its types (Stateful Firewall & Stateless Firewall)
- Virtual Private network (VPN)
- VPN Technologies (PPP, PPTP, IPSec)
- LAN Networking Devices (Router, Switch)
- Virtual Local Area Networks (VLANs)
  


## Practical Activity

- Configured firewall rules to block malicious traffic from reaching the web server.
- Completed the assigned task.
- Retrieved the required flag.


## Key Learnings
- Learned how port forwarding enables external devices to access services within a private network.
- Understood the purpose of firewalls and the difference between stateful and stateless firewalls.
- Learned how VPNs provide secure and encrypted communication over public networks.
- Gained an understanding of common VPN technologies, including PPP, PPTP, and IPSec.
- Understood how VLANs logically divide a physical network into multiple isolated networks.

  
## Summary
Through this room, I learned how different networking technologies work together to improve connectivity, security, and network management. I gained an understanding of port forwarding, firewalls, VPNs, and VLANs, along with their roles in protecting network traffic and organizing communication efficiently.
