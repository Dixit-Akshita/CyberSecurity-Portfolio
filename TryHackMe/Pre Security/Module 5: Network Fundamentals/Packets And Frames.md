
# Packets And Frames

Platform: TryHackMe 
Path: Pre Security 
Module: 2 
Status: Completed

## Overview
This room introduced the fundamentals of packets and frames, the TCP/IP model, UDP, and commonly used network ports. It explained how data is transmitted across a network and how different communication protocols operate.

## Topics Covered
- Packets and Frames
- TCP/IP (The Three Way Handshake)
- UDP/IP
- Ports

## Practical Activity

- Reassembled the TCP three-way handshake to establish a network connection.
- Connected the target IP address to the assigned port.
- Successfully completed all assigned tasks.
- Retrieved the required flag.

## Key Learnings
- Learned the difference between packets and frames.
- Understood the structure of an IP packet and its common headers.
- Learned how the TCP three-way handshake establishes a reliable connection.
- Understood how UDP provides fast, connectionless communication.
- Gained knowledge of common network ports and the services associated with them.

## Summary
Through this room, I learned how packets and frames are used to transmit data across a network. I understood the differences between TCP and UDP, how the TCP three-way handshake establishes a reliable connection, and why UDP is preferred for speed-sensitive applications. I also learned about common network ports and their role in network communication.
