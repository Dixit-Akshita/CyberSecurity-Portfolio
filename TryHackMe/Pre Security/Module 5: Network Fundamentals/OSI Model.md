## Overview
This room introduced the OSI (Open Systems Interconnection) Model, a 7-layer networking framework that explains how data moves across a network. It also covered the concept of encapsulation, showing how data is wrapped with different headers at each layer before transmission.


## Topics Covered
- Introduction to the OSI Model?
- Layer 1- Physical
- Layer 2- Data Link
- Layer 3- Network
- Layer 4- Transport
- Layer 5- Session
- Layer 6- Presentation
- Layer 7- Application
- Encapsulation Process


## Key Learnings
- Learned the purpose and responsibilities of all seven OSI layers.
- Understood how data is encapsulated and de-encapsulated during communication.
- Identified which networking protocols operate at different layers.
- Built a strong foundation for networking concepts used in cybersecurity.

  
## Summary
The OSI Model provides a standardized way to understand how network communication works. Each layer performs a specific function, allowing devices and applications to communicate efficiently. Understanding the OSI model is fundamental for troubleshooting networks and analyzing security incidents.
