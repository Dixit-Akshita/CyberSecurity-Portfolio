## 📖 About the Event

Hacker Holidays is an interactive cybersecurity event where participants investigate the mysterious **Byte Lotus Hotel** through a series of daily challenges.

Each day introduces new scenarios and practical exercises covering different areas of cybersecurity while progressing through an ongoing storyline.
