# TryHackMe Hacker Holidays 2026 – Day 2: Room 404

## Overview

As part of the **TryHackMe Hacker Holidays 2026 CTF**, I completed **Day 2 – Room 404**, a beginner-friendly web security challenge focused on discovering hidden resources within a web application.

> **Note:** This write-up documents my learning and intentionally excludes walkthrough steps, commands, and flags to respect TryHackMe's learning guidelines.

## Challenge Details

* **Event:** TryHackMe Hacker Holidays 2026
* **Room:** Room 404
* **Category:** Web
* **Difficulty:** Very Easy

## Learning Objectives

* Understand Web Directory Enumeration
* Explore Hidden Content Discovery
* Learn the role of reconnaissance in web security
* Recognize the risks of exposed development and backup files
* Understand how hidden resources increase a web application's attack surface

## Key Takeaways

* Not every accessible resource is linked through the application's interface.
* Directory enumeration is a fundamental reconnaissance technique used during web security assessments.
* Misconfigured web servers may unintentionally expose sensitive files or directories.
* Proper deployment and regular security reviews help reduce unnecessary exposure.

## Skills Practiced

* Web Reconnaissance
* Directory Enumeration
* Identifying Hidden Resources
* Web Security Fundamentals
* Analytical Thinking
